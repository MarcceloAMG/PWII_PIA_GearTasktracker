GearTaskTracker es un proyecto de gestión de equipos de trabajo y asignación 
automatica o manual de tareas con funcionalidades administrativas para
medir el rendimiento de cada miembro del equipo.

Cuenta con 2 versiones: basica y premium las cuales ambas son funcionales;
sin embargo, la basica se ve limitada y tiene versiones distintas de las
herramientas adminsitrativas, a diferencia de la premium que posee todas 
las funciones y además permite ver una nueva version de las pantallas
administrativas (como reportes y estadisticas de forma diferente a la basica)
